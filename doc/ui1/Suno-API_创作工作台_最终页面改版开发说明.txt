Suno-API 创作工作台页面改版开发说明
版本：Final UI Spec
用途：用于 AI Coding / 前端开发直接改造现有页面
基准：视觉、布局、尺寸、层级、配色、交互入口严格以最终确认设计图为准；历史截图仅用于保留功能，不作为视觉参考。

============================================================
一、改版总原则
============================================================

1. 最终页面必须以“浅色、白底、黑白灰控件、轻边框、低阴影、圆角卡片”的最终设计图为唯一视觉标准。
2. 不允许重新设计，不允许擅自增加模块，不允许用旧页面的深色主题、橙色主色、大面积渐变、强阴影替代最终设计。
3. 现有业务逻辑、接口调用、数据结构、生成流程、歌曲状态、播放逻辑、收藏逻辑、更多菜单、分页逻辑等必须保留。
4. 如果原项目功能入口与最终设计图位置冲突：
   - 功能逻辑保留；
   - 入口位置、控件形式、卡片结构、视觉层级按照最终设计图调整；
   - 不要为了“保留旧 UI”而破坏最终设计图结构。
5. 页面分为 3 个固定层级：
   - Header：顶部全宽固定导航；
   - Main：中间左右双栏工作区；
   - Player：底部全宽固定播放器。
6. Main 左侧为创作面板，右侧为歌曲结果列表。
7. 页面主体不要出现整页浏览器级纵向滚动；优先采用“固定 Header + 固定 Player + 中间区域内部滚动”。
8. 所有尺寸均以最终设计图约 1672×941 的桌面画布作为视觉基准；实际实现时允许 2～4px 误差，但结构比例不能改变。
9. 所有 UI 尽量使用现有设计系统变量统一控制，不要把颜色、圆角、间距散落硬编码在大量组件中。
10. 所有文本均使用简体中文；字体优先使用系统中文无衬线字体。

说明：
- 页面不是纯白背景，最外层建议使用非常浅的灰白 #F7F8FA。

- 彩色仅允许用于歌曲标签、状态提示、小型强调元素，不能破坏黑白灰主视觉。
- 不使用大面积渐变背景。
- 阴影必须非常轻，主要通过边框和层级区分区域。

三、页面整体结构
============================================================

桌面基准布局：
- Page 宽度：100vw；
- Page 高度：100vh；
- Header：约 70～72px，高度固定；
- Player：约 82～86px，高度固定；
- Main 高度：calc(100vh - Header - Player)；
- Main 左右双栏；
- 左栏宽度约 31%；
- 右栏宽度约 69%；
- 在 1672px 画布下：
  - 左侧创作区约 500～510px；

  left: 0;
  right: 0;

   - font

   - active
   - disabled
   - scrollbar

============================================================
二十二、禁止项
============================================================

以下做法禁止出现：

1. 禁止重新使用旧版全黑 / 深灰背景。
2. 禁止恢复旧版蓝橙大渐变生成按钮。
3. 禁止给普通卡片添加明显发光或重阴影。
4. 禁止把右侧歌曲改成大卡片瀑布流。
5. 禁止改变左侧约 31% / 右侧约 69% 的桌面布局关系。
6. 禁止把 Header、Player 放进可滚动内容中。
7. 禁止擅自增加侧边导航栏。
8. 禁止擅自增加新统计卡片、Banner、推荐模块。
9. 禁止擅自改变顶部导航项。
10. 禁止把最终图不存在的彩色品牌元素大量加入。
11. 禁止为了“现代化”把所有控件改成玻璃拟态、渐变、霓虹。
12. 禁止删除旧功能逻辑；只允许重新组织入口。
13. 禁止使用不同页面完全不同的 UI 语言。
14. 禁止把歌曲列表改成信息密度过低的大卡片。
15. 禁止让单条歌曲描述无限换行撑高列表。
