本次交付三套基于现有声序功能的 UI 设计方向和可切换概念预览，用于选择布局、信息层级与玻璃使用范围。正式应用页面尚未实施。

| 项目 | 要求 |
|---|---|
| 用户可见结果 | 三套布局方案，共用参考站的玻璃组件语言 |
| 数据流 | 预览中的示例描述、歌词与作品仅在本地交互，不提交生成或上传请求 |
| 影响范围 | 本文、AGENTS.md、聊天中的概念预览 |
| 验证方式 | 浏览器检查参考站文档与材质；检查三套预览、切换模式、费用提示和歌词结构插入 |
| 已知限制 | 预览使用 CSS 表达材质方向，未接入参考 SDK，不代表已实现真实折射或菜单形变 |

## 现有界面依据

- Vue 3、TypeScript、Element Plus；主页面为创作工作台、作品库和个人中心。
- 创作页面包含简易、高级、音效三种模式，模型选择、上传音频、人声克隆、歌词工具、Max Mode 和作品列表。
- 主导航同时呈现测试管理员、赚额度、充值、客服、教程、通知和账户等入口，主次关系需要调整。
- main.ts 加载多层样式，monochrome-theme.css 和 glass-theme.css 同时参与覆盖。
- monochrome-theme.css 对封面或图片应用灰度；glass-theme.css 以模糊、半透明背景和阴影为主。

## 共用组件规则

参考站提供 Clear 和 Regular 材质、明暗外观、连续圆角、折射参数、按压拖动反馈以及从触发器展开的菜单动画。方案之间主要比较布局，共用同一套材质逻辑。

| 部件 | 材质与行为 |
|---|---|
| 主导航、悬浮播放器、短工具栏 | Clear：背景透射、可见边缘高光、胶囊或连续圆角 |
| 菜单、音色选择、风格选择弹层 | Regular：更稳定的文字对比，打开时与触发器保持空间关系 |
| 歌词与描述输入区域 | 稳定底色；长文本阅读优先，外围使用 Regular 层级 |
| 模式切换 | 胶囊容器与移动选中指示，切换时保持控件位置稳定 |
| 按钮与开关 | 同一高光、圆角和按压反馈体系；关/开与禁用状态清晰 |
| 播放进度与音量 | 统一滑杆语言；操作命中区域充分，保留键盘控制 |
| 背景与封面 | 恢复封面色彩；背景可借用封面低饱和色调，文字区域维持稳定对比 |
| 无障碍与降级 | 尊重减少动态效果设置；不支持效果时使用稳定实色或磨砂底色 |

参考站展示的 refraction 默认值为 60 像素，这是组件默认参数，不能直接作为声序所有控件的设计值。需在真实背景和尺寸下逐项校准。

## 三套方案

| 方案 | 布局 | 玻璃重点 | 适合场景 | 相对改动量 |
|---|---|---|---|---|
| 清透工作台（推荐） | 左侧创作、右侧最近作品、底部悬浮播放器；高级参数逐步展开 | 胶囊导航、模式切换、生成操作和播放器使用 Clear；编辑与作品内容保持稳定层级 | 日常生成、歌词编辑与版本试听 | 中 |
| 沉浸音乐空间 | 当前作品封面与版本对比占主要视觉区域，创作表单集中在旁侧 | 背景借用封面色调，播放器与导航浮在背景上 | 展示作品、灵感探索与试听 | 较大 |
| 深色专业录音室 | 宽歌词编辑区搭配生成设置栏，作品库作为次级工作区 | 深色 Regular 承载编辑，Clear 承载播放与短操作 | 高级创作、人声克隆、长歌词和频繁调参 | 较大 |

推荐清透工作台作为主布局，结合沉浸音乐空间的封面色彩与背景处理。这里的“清透”描述玻璃材质，不限定必须使用浅色主题。

## 推荐方案的页面调整

| 内容 | 修改前 | 建议修改后 |

| 作品区域 | 多个同等重量的卡片 | 紧凑作品行；当前选中版本突出，保持名称、风格、版本和时长可读 |

## 正式落地顺序与边界

1. 先在 Vue 3 中验证一个独立玻璃播放器，核对透射、折射、高光、按压反馈及性能。参考站示例采用 React API，不能直接作为 Vue 组件导入；需确认是否有可复用底层或评估局部适配。不要为视觉改造默认迁移整个框架。
2. 验证通过后统一导航、模式切换、按钮、开关、滑杆和弹层的组件语言。
3. 调整 CreateView.vue 的信息层级，并统一 PlayerBar.vue 与相关播放器弹层。
4. 整理当前主题覆盖，恢复封面色彩，检查作品库、个人中心及创作弹窗。
5. 执行 npm run build；回归桌面和手机尺寸、键盘操作、减少动态效果及浏览器降级表现。真实生成与扣费另列业务验收，不由外观预览触发。

预计涉及 frontend/src/App.vue、frontend/src/views/CreateView.vue、frontend/src/components/PlayerBar.vue 及现有主题样式；最终文件范围由采用的方案与适配验证决定。
